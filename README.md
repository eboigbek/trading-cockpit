# Trading-Cockpit

Paper-Trading-Bot für EUR/USD und GBP/USD, läuft alle 5 Minuten über GitHub Actions.

- **Cockpit:** https://eboigbek.github.io/trading-cockpit/
- **Not-Aus / Steuerung:** Reiter *Actions* → *Steuerung* → *Run workflow*
- **Strategie-Test:** Reiter *Actions* → *Strategie-Test* → *Run workflow*
- **Code und Anleitung:** [trading-cockpit/](trading-cockpit/README.md)

Spielgeld-Simulation, keine Anlageberatung.
